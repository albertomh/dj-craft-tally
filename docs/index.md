# dj-craft-tally

`dj-craft-tally` is a reusable Django app to help makers track projects and
inventory in their workshop.

The project is in its early stages. Documentation will grow alongside its stable
models, Django-admin workflows, and public APIs.

## Development

Install the documentation tools and preview the site locally:

```sh
uv sync --group docs
uv run zensical serve
```

Build the static site with:

```sh
uv run zensical build --clean
```
